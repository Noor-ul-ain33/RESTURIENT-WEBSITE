# RESTURIENT-WEBSITE
This is a responsive and modern restaurant website built using HTML5, CSS3, and JavaScript. The website is designed to provide users with a smooth and user-friendly experience while exploring menu items, services, and restaurant details.

📌 Features
Fully responsive design (mobile, tablet, desktop)
Modern and clean UI design
Interactive navigation menu
Restaurant menu section with food items
About section for restaurant introduction
Contact form for customer inquiries
Smooth scrolling and hover effects
Technologies Used
HTML5
CSS3
JavaScript
